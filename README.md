# PedidoFlow

Arquitetura inicial do MVP do PedidoFlow.

Objetivo: permitir que pequenos negócios criem uma vitrine digital, recebam pedidos pelo fluxo do site e encaminhem o pedido pronto para o WhatsApp.

## Stack prevista

- Next.js + TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase (Auth + PostgreSQL + Storage)
- Anime.js
- Zod
- React Hook Form
- Lucide React

## Regra de desenvolvimento

Construir um sistema por vez. Não adicionar dependências sem necessidade.

Ao finalizar cada etapa funcional, fazer um commit Git.

Exemplos:

- `chore: scaffold projeto`
- `feat: criar landing page`
- `feat: adicionar autenticacao`
- `feat: criar gerenciamento de produtos`
- `feat: criar pagina publica da loja`
- `feat: adicionar carrinho e whatsapp`
- `fix: corrigir fluxo de pedido`
